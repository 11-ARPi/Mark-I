# Introduction
Below is a tutorial that will help you build your own robotic hand that closes and opens its fingers using an IR sensor.


# Materials needed:
- 1 Arduino Uno
- 1 IR sensor
- 5 servomotors (for each finger)
- 1 or 2 breadboards
- Jumper wires
- 2/3mm elastic rope
- Transparent string
  
## Optional:
  - 1 power bank (to power the Arduino)
